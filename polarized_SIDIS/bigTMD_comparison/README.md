# Reserved later observable comparison

The current calculation keeps the large-transverse-momentum SIDIS measurement. A low-transverse-momentum/TMD or hadron-in-jet comparison requires its own measurement and matching conventions. This folder does not currently establish an independent polarized NLO benchmark. The current reference gates compare the reconstructed unpolarized sector, while the additional spin components have the validation scope stated in the physics report.

The original folder note is preserved in [README_code.md](README_code.md). Return to the [main guide](../README.md) or [physics report](../polarized_SIDIS_report.pdf). There is no additional completed stage or numerical result hidden in this directory.
