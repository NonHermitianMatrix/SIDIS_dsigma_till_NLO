# Hqqbar MadGraph tree-real check

## Scope and conclusion

This directory is an isolated, read-only-upstream check of the Hqqbar tree-real
process

`e- u -> e- u u u~`

through a spacelike photon, with the `Z` and Higgs excluded. MadGraph generated
exactly eight diagrams. No accepted Hqqbar source, macro, cache, or result was
edited; the only Hqqbar inputs are byte-identical copies under
`upstream_copies/`.

The requested unrestricted four-dimensional comparison directly against raw
S08/S10 is not a finite observable. At an interior rational `s23` point, copied
S10 has exact-zero double poles but nonzero simple collinear poles:

- `Pg`: `2.287716611662530660016086883831e-8 / epsilon`
- `PPP`: `-9.36688755227387732992224229376905e-6 / epsilon`

An interior `s23` restriction removes endpoint distributions but does not
remove the initial/final angular collinear regions. Those poles remain until
the S11/S12 MS-bar factorization stages, whereas MadGraph is four-dimensional.
The valid raw-real check therefore uses the copied pre-angular S06/S07 tensor
with identical invariant separation cuts on the local and MadGraph sides.

The finite-bin result is

- MadGraph: `3.66827994997779932e-4 pb`
- copied-S07 local: `3.66827994997779769e-4 pb`
- Monte Carlo standard error: `5.98431860980528321e-6 pb`
- local minus MadGraph: `-1.62800968255521792e-19 pb`
- integrated relative difference: `4.43807371508019922e-16`

Across all 27,851 accepted common points, the median, 99th-percentile, and
maximum relative differences are respectively `3.3285e-15`, `6.6937e-14`,
and `2.1790e-11`.

## Normalization and bookkeeping

The local reconstruction follows the Hqqbar channel README and paper Eqs.
(3), (5), (7)-(9), and (16).

1. Copied S07 already contains the sum over final quark spins/colors and the
   incoming-quark average `1/(2 Nc)`.
2. Its amplitudes are quark-charge stripped and contain `EL^2 g_s^4`.
3. The comparison restores the physical up-charge factor `e_u^2 = 4/9`, the
   electron vertex factor `e^2`, and the photon propagator `1/Q^4`.
4. The usual spin-averaged leptonic tensor supplies the incoming-electron
   average.
5. The one deferred identical-spectator factor `1/2!` is applied exactly once,
   matching MadGraph's `IDEN=24` together with the two initial spin averages
   and incoming-quark color average.
6. Couplings are `alpha_s=0.118` and `alpha_em^-1=132.507`, matching the pinned
   MadGraph parameter card.
7. S07's `Pg` and `PPP` reconstruct the azimuth-independent `F1` and `F2`.
   A fixed MadGraph orientation also contains the azimuthal tensors explicitly
   omitted in the paper. Four equally spaced rotations of the lepton plane at
   fixed `p`, `q`, and hadronic invariants remove all rank-two azimuthal
   harmonics. At the reference point this average agrees with copied S07 to
   `2.4023e-15` relative.

## Finite common bin

The incoming massless partonic energy is `sqrt(s)=1000 GeV`. The deterministic
sample uses 120,000 massless four-body RAMBO trials generated by NumPy PCG64
with seed `2026081801`. Rejected events enter both estimators as exact zeros.
The invariant, azimuth-symmetric cuts are

- `0.08 <= Q2/s <= 0.40`
- `0.25 <= sHat/s <= 0.75`
- every `sij/sHat >= 0.05`
- every `(-ui)/(sHat+Q2) >= 0.05`
- every `(-ti)/(sHat+2 Q2) >= 0.03`

The estimator is

`sigma = Phi_4(s)/(2s) * sum_accepted(|M|^2) / N_trials`,

with the standard massless measure

`Phi_4(s) = s^2 / (24 (4 pi)^5)`.

## Stage map

1. `s01_install_madgraph.sh`: verifies and installs the pinned official
   MG5_aMC 3.7.0 archive and local Python dependency.
2. `s02_generate_hqqbar_standalone.mg5`: generates the photon-only eight-
   diagram standalone matrix code.
3. `s03_madgraph_c_bridge.f90`: exposes initialization, evaluation, and process
   metadata through a minimal ISO-C bridge.
4. `s04_direct_madgraph_reference.f90`: evaluates MadGraph's generated routine
   directly at a deterministic massless point.
5. `s05_validate_madgraph_bridge.py`: proves direct/bridge identity, PDG order,
   `IDEN=24`, conservation, masslessness, and identical-u exchange symmetry.
6. `s06_inspect_copied_s07_schema.wl`: inspects the copied projector schema and
   inert propagator/coupling forms without printing expression bodies.
7. `s07_validate_local_matrix_element.wl`: maps all propagators to invariants
   and reconstructs the azimuth-independent local matrix element.
8. `s08_validate_azimuthal_average.py`: proves the four-angle MadGraph average
   equals the local projected reference at `2.4e-15` relative.
9. `s09_build_four_dimensional_evaluator.wl`: creates and validates the compact
   unit-coupling SU(3), `D=4` invariant evaluator using the truthful WVM
   backend (about 126,600 evaluations/s in production).
10. `s10_generate_cut_bin_madgraph.py`: generates the deterministic finite-bin
    sample and evaluates the four-angle MadGraph matrix on every accepted row.
11. `s11_evaluate_local_cut_bin.wl`: evaluates copied S07 on exactly the same
    rows and enforces pointwise agreement.
12. `s12_integrate_common_cut_bin.py`: applies the common phase-space/flux
    normalization and produces the correlated integrated comparison.
13. `s13_validate_madgraph_check.py`: independently verifies hashes, schemas,
    row counts, checks, upstream copy identity, and the final result.

Run the numbered stages in order. The primary numerical result is
`s12_integrated_comparison.json`; the point-level comparison is
`s11_pointwise_comparison.json`.
